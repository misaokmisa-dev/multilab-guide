MINECRAFT / ITEM ID & COMMAND FINDER

日本語から、アイテムIDと/giveを一発検索

アイテムの日本語名・英語名・IDを入力すれば、英語名とJava版の /give コマンドがその場で分かります。コピーボタンで手入力の間違いを防ぎます。登録不要・無料。

1. 調べたいアイテムを検索

アイテムを選ぶとコマンドを表示します。

アイテムIDと /give の使い方

例：/give @s minecraft:diamond 64。コマンドを使うにはゲーム内の権限が必要です。この検索はJava版のアイテムIDを基準にしています。

統合版（Switch・スマホ・PS等）に注意：Java版と一部アイテムのID・コマンド仕様が異なります。統合版の全アイテムについて互換性を保証するものではありません。公式の統合版 /give の仕様を確認してください。

Java版のアイテム名・素材データ：PrismarineJS minecraft-data。非公式ツールです。
