MINECRAFT / ITEM ID & COMMAND FINDER

日本語から、アイテムIDと/giveを一発検索

アイテムの日本語名・英語名・IDを入力すれば、英語名とJava版の /give コマンドがその場で分かります。コピーボタンで手入力の間違いを防ぎます。登録不要・無料。

背景：Minecraft公式サイト掲載の画像

広告
アイテムID・コマンド検索材料まとめて逆算ツール全アイテム図鑑

1. 調べたいアイテムを検索

アイテムを選ぶとコマンドを表示します。

アイテムIDと /give の使い方

例：/give @s minecraft:diamond 64。コマンドを使うにはゲーム内の権限が必要です。この検索はJava版のアイテムIDを基準にしています。

統合版（Switch・スマホ・PS等）に注意：Java版と一部アイテムのID・コマンド仕様が異なります。統合版の全アイテムについて互換性を保証するものではありません。公式の統合版 /give の仕様を確認してください。

Java版のアイテム名・素材データ：PrismarineJS minecraft-data。非公式ツールです。

Java版 /give コマンドの使い方：実例で確認

この検索ツールの役割は、日本語から正しい英語IDを見つけることと、個数を入力してコマンドを組み立てることです。アイテム一覧で名前を探すより、スペル違いやアンダースコアの入力間違いを減らせます。ここでは自分でコマンドを調整する際の考え方を説明します。

例1：自分にダイヤモンド64個を渡す

/give @s minecraft:diamond 64。@sはコマンドの実行者、minecraft:diamondはJava版のアイテムID、末尾の64は渡す個数を意味します。自分がゲーム内チャットから実行する基本例です。チート・コマンドが許可されていなければ実行できません。

例2：近くのプレイヤーに松明16個を渡す

/give @p minecraft:torch 16。@pは実行位置に最も近いプレイヤーを指します。コマンドブロックやマルチプレイで利用すると、思っていない相手が選ばれる可能性があります。実行者本人を示す@sとは意味が違うため、対象を確認してから利用してください。

例3：スペース・大文字・日本語が原因で動かないとき

アイテムの表示名と内部IDは一致しません。たとえば「ダイヤモンドの剣」のJava版IDはminecraft:diamond_swordです。英語名の空白をそのまま書かず、検索結果の「アイテムID」からコピーした文字列を使います。MODや開発版にしか存在しないアイテムを、通常のバージョンで使っても認識されません。

実行できない場合の切り分け

  1. 権限を確認：シングルプレイではコマンド実行の許可、マルチプレイではサーバー管理者が設定した権限が必要です。「不明なコマンド」と表示されたら、まず権限と入力した先頭の/を確認します。
  2. 版を確認：このページの検索対象はJava版の登録データです。統合版のコマンド構文・追加アイテム・データ形式は一致しない場合があります。
  3. 対象を確認：@sはチャットで実行するプレイヤーの想定です。コマンドブロックでは実行主体がプレイヤーとは限らないため、用途に応じて対象指定を変更します。
  4. アイテムと数量を確認：IDのタイプミス、起動バージョンでの未実装、インベントリの空き不足を確認します。大量に渡す前に数量1で試すと原因を分けやすくなります。

名前が曖昧なときの調べ方

検索欄に「たいまつ」「剣」「ダイヤ」などの一部分を入力すると、関連するアイテム候補を選べます。候補を開いてアイテムIDを確認し、必要数を変更したらコマンドをコピーしてください。使い道やクラフト材料も必要なら全アイテム図鑑、複数の完成品に必要な素材を調べたいなら材料まとめて逆算ツールを利用できます。
