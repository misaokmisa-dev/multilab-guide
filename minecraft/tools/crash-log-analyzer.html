MINECRAFT JAVA / TROUBLESHOOTING

マイクラのクラッシュログを
その場で診断する。

「起動しない」「MODを入れたら落ちた」――その原因はPCの性能不足とは限りません。latest.log または Crash Report のエラー記述を端末内で調べ、まず確認したい項目を日本語で整理します。

無料・登録不要ファイルは送信しませんJava版向けスマホでも解析可

1. ログを選んで原因候補を調べる

ログ内のエラーや注意メッセージを、既知のパターンと照合します。原因を自動で断定するものではありません。

まだログを読み込んでいません。

診断結果：原因の候補と確認する順番

ログ内の単語の一致に基づく候補です。複数のエラーが重なる場合、根本原因とは別のエラーが表示されることがあります。誤診防止のため、個人情報を含む生ログや端末内のファイルは送信・保存しません。

2. ログが見つからないとき

Windows（通常のMinecraftランチャー）

  1. Win＋R を押す。
  2. %appdata%\.minecraft を入力して開く。
  3. 直近のログは logs/latest.log、クラッシュレポートは crash-reports フォルダ内の最新の .txt です。

起動プロファイルでゲームフォルダを変更した場合は、そちらを確認してください。

Mac・他のランチャー

Macの通常の保存場所は ~/Library/Application Support/minecraft/ です。Modrinth App・CurseForge・Prism Launcherなどは各インスタンスのゲームフォルダから logs や crash-reports を探してください。

注意：ファイル名が latest.log.gz の場合は圧縮された過去ログです。展開して .log や .txt を選んでください。

3. 何を検出できる？

MOD依存・ローダー必要なMODが見つからない、対応バージョンが一致しない、読み込みに失敗した
Java実行環境Javaバージョンやクラス形式の非互換性
メモリ不足OutOfMemoryErrorなどの明示的なエラー
描画・GPUGLFW / OpenGL / 描画初期化の失敗
Mixin競合MODがゲーム内部の処理を書き換える際の失敗
アクセス権・接続ファイル権限・サーバーのポート競合・接続エラー

これはパターン認識型の診断です。MODの作者名や原因MODを必ず正しく特定できるわけではなく、PCの交換や有料サーバーの購入を勧める前に、無料の対処から試すためのツールです。

4. 直らないときの次の一手

MOD起動失敗の解決ガイドゲーム版・依存MOD・ローダーを順に確認する ゲームが重い・カクつくFPS / メモリ / サーバー遅延を切り分ける 友達と遊ぶサーバー容量を診断参加人数やMOD数から必要条件を整理 PCの性能を見直す前に推奨スペックを無料で確認する

よくある質問と解析の限界

「原因が見つかりません」と出た場合は？

エラーメッセージがログに記録されていない場合、既知の文字列に一致しない場合、ファイルのサイズ制限によって末尾が欠けている場合などに起こります。最も新しいログ、または crash-reports の最新ファイルを試し、画面上のエラーメッセージも確認してください。

PC性能が足りないと断定できる？

できません。OutOfMemoryError のような明示的なメッセージがあっても、原因は割り当て設定、MOD構成、実行環境の問題かもしれません。まず無料でできる設定確認とバックアップを優先します。

ファイルがインターネットへアップロードされる？

この診断処理ではアップロードしません。選択ファイルの読み取り・文字列検査・診断結果生成はブラウザ内のJavaScriptで完結し、ログ内容を送るAPI通信も設けていません。ただし通常のページ閲覧によるアクセスログはサイト全体のプライバシーポリシーに従います。ログにはユーザー名やサーバーアドレスなどが入る場合があるため、他者に共有するときは別途確認してください。

どこを根拠に判定している？

公開されている Fabric公式Crash Reports・ログの見つけ方・Modrinthの問題切り分け解説を参照し、エラーの検出ルールと日本語の確認手順を独自実装しています。AIによる未知の原因推定や実機での再現検証は行いません。2026年11月6日公開。
