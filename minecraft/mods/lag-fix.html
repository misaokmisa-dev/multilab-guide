マイクラのMODが重いときの対処法

MODを入れたらFPSが下がる、数秒ごとに止まる、地形の読み込みが遅い。症状によって確認する場所は異なります。PCを買い替える前に無料でできる切り分けから始めましょう。

対象：Minecraft Java版。 統合版ではMODや設定の仕組みが異なります。以下は一般的なトラブル確認手順で、特定のPC・MOD構成の改善を保証するものではありません。ワールドと導入構成は先にバックアップしてください。

どんな症状が出ている？

最も近い症状を選ぶと、先に調べる項目が切り替わります。入力内容をサーバーへ保存する機能はありません。

上の症状を選ぶと、具体的な確認順が表示されます。

画面が重いとき

  1. 影MOD・高負荷テクスチャを一度オフにして、同じ場所で比較します。
  2. 描画距離・シミュレーション距離を下げて比較します。
  3. ビデオドライバーの更新と、適切なGPUが使われているかを確認します。
  4. 改善しなければMOD構成を分けて確認します。

便利・軽量化MODを比較する →

定期的な停止・カクつき

  1. ブラウザなどの同時起動アプリを終了し、使用メモリを確認します。
  2. Java版ランチャーのメモリ割り当てが極端に少ない・多すぎる設定になっていないか調べます。
  3. 直前に追加したMODと前提ライブラリを確認し、少数ずつ有効化して比較します。
  4. MODパック提供元の推奨メモリ量も確認します。

安全なメモリ確認手順を見る →

地形の読み込みが遅いとき

  1. 描画距離とシミュレーション距離を少しずつ下げます。
  2. 新規ワールドを作り、同じMOD構成で比較します。
  3. ワールド生成に影響するMODを一つずつ確認します。
  4. ストレージ容量や、ほかの重い処理の同時実行も確かめます。

既存ワールドからMODを外す前には必ずバックアップしてください。

マルチでの遅延

  1. 自分の画面のFPSが安定しているか先に確認します。
  2. FPSは安定しているのにブロック破壊やMobの反応が遅い場合、サーバー処理やネットワークを切り分けます。
  3. 参加者とサーバーのMOD・ローダー・バージョンを確認します。
  4. サーバーの負荷、接続状態、描画設定を管理者と一緒に確認します。

起動失敗やクラッシュは別の原因を確認

  1. 表示されたエラーメッセージやクラッシュログを控えます。
  2. バージョン、ローダー、依存MODの一致を確認します。
  3. バックアップした別環境で、直前に追加したMODを取り除いて試します。

MODが起動しないときの詳しい手順 →

まず無料で確認する5つのこと

  1. 同じ場所・同じ設定で比較する。 FPSやカクつきを判断するときは、影MODや描画距離を変える前後で、できるだけ同じワールド・同じ場所を使います。ワールド生成中だけ重い場合は、平常時と分けて考えます。
  2. MODを外す前にバックアップ。 新しいブロックやワールド生成を追加するMODを外すと、保存データに影響する可能性があります。コピーしたテスト用ワールドと別プロファイルで切り分けます。
  3. GPU・OSの状態を確認。 グラフィックドライバーの更新やOSの更新を確認します。ノートPCでは電源設定や冷却状態でパフォーマンスが変わる場合があります。
  4. メモリを増やせば必ず改善する、とは考えない。 Java版に割り当てる量は、PCの物理RAMや同時起動アプリの余裕を残して設定します。すべてのメモリを割り当てる方法は避けましょう。
  5. MODの組み合わせを分けて調べる。 同じ処理を変更する最適化MOD同士が競合する可能性もあります。対応版・前提MOD・ローダーの条件は各作者の配布ページを確認します。

設定変更の効果を数字で比較する

同じワールド・同じ場所で、変更前と変更後のFPSを記録しましょう。F3画面などで確認できる値を入力します。瞬間的な最高FPSではなく、同じ場面で数十秒観察したおおよその値を使うと比較しやすくなります。結果はこの画面内だけで計算し、送信・保存しません。

両方のFPSを入力すると、差と変化率を表示します。

FPSの差は同じ条件での参考値です。描画距離・MOD構成・ワールド内の位置・プレイ時間が異なる場合、設定変更だけの効果とは判断できません。マルチプレイの通信遅延はFPSでは測れません。

Java版のメモリ割り当てを確認する方法

Minecraft Launcherを使っている場合、起動構成の編集画面にあるJVM引数の -Xmx が、Java版に割り当てるメモリ上限に関係します。たとえば -Xmx4G なら概ね4GBが上限です。ただし、推奨値はMinecraftのバージョン・MODパック・PCの総メモリなどに左右されます。

  1. 現在の起動構成とワールドをバックアップします。
  2. PCの物理RAM容量と、同時に動くアプリの使用量を確認します。
  3. MODパックに推奨値がある場合はその指示を優先します。
  4. 少しずつ変更して、同じ場所で挙動を比較します。

注意： RAMが足りないPCで割り当てを無理に増やすと、OS側の余裕がなくなり逆効果になる場合があります。Java版のバージョンによって標準割り当て量も異なるため、固定の「全員これでOK」という値は掲載していません。

公式手順：Minecraft Help：メモリ割り当ての確認・変更

それでも重い場合、PCのどこを確認する？

無料の設定変更やMODの切り分けを行っても改善しない場合は、CPU・GPU・メモリ・ストレージのうち、どの部分がボトルネックになりやすいかを用途ごとに考えます。必ずしもPCの買い替えが必要なわけではありません。

よくある質問

軽量化MODを1つ入れれば必ず速くなりますか？

いいえ。描画やメモリなど改善対象が違い、PC構成やMODとの相性にも左右されます。便利・軽量化MODの一覧で候補を探し、対応バージョンと互換性を確認してください。

MODを入れる前は軽かったのに、突然重くなったのはなぜ？

最近追加・更新したMOD、設定変更、ワールドの状態、ドライバーやバックグラウンド処理など複数の原因が考えられます。直前の変更を一つずつ元に戻して比較するのが基本です。

統合版のアドオンでもこの方法を使えますか？

描画設定や端末負荷の考え方は参考になりますが、MODローダーやJVMメモリ割り当てはMinecraft Java版向けです。統合版には同じ手順をそのまま当てはめないでください。
