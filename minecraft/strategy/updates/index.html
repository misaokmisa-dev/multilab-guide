実装日

実装日未定。Java版ではSnapshot（開発版）で一部の新要素を試せます。

2026年10月27日に公開されたSnapshot 6では、雪レンガと冷たいサルファーキューブの特性が追加されました。正式リリース済みのJava版最新大型更新は ver.26.3（2026年9月15日）です。

MAIN HIGHLIGHTS

目玉情報

01 / NEW BIOME注目

新バイオーム「氷の洞窟」

寒い地域の地下に生成される新しい洞窟。氷塊と方解石が広がり、天井にはつらら、地面には光る氷の結晶が現れます。通常の洞窟とは違う探索体験が目玉です。

登場：Snapshot 3（10月6日）

02 / NEW MOB注目

新敵「フロストバイト」＆凍結攻撃

寒い場所に登場するゾンビの亜種。近距離で凍結効果を与え、離れると氷の球を投げてくるのが特徴です。凍結状態ではジャンプが制限され、ダメージを受けることもあります。

登場：Snapshot 3（10月6日）

03 / NEW BLOCK

「脆い氷」＆裂け目

踏むとひびが入り、やがて壊れてしまう新しい氷。氷の洞窟にできる裂け目と組み合わさり、移動時の新たな危険になります。

登場：Snapshot 4（10月13日）

04 / MUSIC

ジュークボックスの連続再生

ジュークボックスの上にチェストを置くことで、チェスト内の音楽ディスクを順番に再生できます。拠点でのBGM管理が便利になります。

登場：Snapshot 4（10月13日）

05 / BUILDING

氷レンガ・雪レンガなど建築素材が増加

氷塊から作るレンガとその階段・ハーフブロック・塀、雪ブロックから作る雪レンガと派生形が追加。寒冷地の建築表現が広がります。

氷レンガ：10月20日／雪レンガ：10月27日

06 / NEW BEHAVIOR

冷たいサルファーキューブ

サルファーキューブが青氷を取り込むと特別な動きに変化。水面の下を一時的に凍らせながら移動する特性が加わります。

登場：Snapshot 6（10月27日）

OTHER CHANGES

ほかに発表された変更

氷の結晶・つらら

氷の結晶は光源になり、つららは環境に応じて落下するなどの危険があります。

氷の球（Ice Ball）

新しい投射物。フロストバイトが使用し、凍結関連のアイテムや仕組みにも関係します。

フレンド機能の改善

フレンド一覧の検索・並び替えなど、オンラインでの使いやすさも改善されています。
