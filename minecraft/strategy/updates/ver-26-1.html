MINECRAFT / JAVA EDITION UPDATE

ver.26.12026年3月24日

Tiny Takeover

動物の赤ちゃんを中心に、見た目・鳴き声・飼育の楽しさが大きく変わった更新です。

Java版正式実装済み実装日：2026年3月24日

HIGHLIGHTS

目玉情報

01 / UPDATE

赤ちゃんMobの見た目・鳴き声

多くの動物の赤ちゃんが新しい外見になり、オオカミ・ネコ・ブタ・ウマ・ニワトリなどには新たな鳴き声も追加されました。

02 / UPDATE

「金のタンポポ」

動物の赤ちゃんの成長を止めることができ、赤ちゃんの姿を長く楽しめます。

03 / UPDATE

名札のクラフト

名札が作成可能となり、ペットやMobに名前を付ける際の入手方法が増えました。

04 / UPDATE

新しい飼育の楽しみ

姿・音・成長の要素が拡充され、牧場や動物園のような拠点作りにも向いています。
